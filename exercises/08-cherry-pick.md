# Exercise 08 — Cherry-Picking

## Tasks

1. On `feature-about`, make a specific commit
2. Note its hash: `git log --oneline`
3. `git switch main`
4. `git cherry-pick <hash>`
5. Verify in `git log --oneline` — new hash, same changes
6. **Bonus:** Try the cross-repo cherry-pick workflow from lesson.md section 18
