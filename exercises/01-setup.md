# Exercise 01 — Setup & Configuration

## Goal
Verify your Git installation and configure your identity.

## Tasks

1. Check your Git version:
   ```bash
   git --version
   ```

2. Set your global name and email:
   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

3. Set the default branch name:
   ```bash
   git config --global init.defaultBranch main
   ```

4. Verify: `git config --list`

5. **Bonus:** `git config user.name`
