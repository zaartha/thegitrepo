# Exercise 06 — Remotes

## Tasks

1. Create a GitHub repo at https://github.com/zaartha
2. `git remote add origin https://github.com/zaartha/your-repo.git`
3. `git remote -v`
4. `git push -u origin main`
5. Edit a file on GitHub directly
6. `git fetch origin && git log origin/main --oneline`
7. `git pull origin main`
