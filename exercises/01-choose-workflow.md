# Exercise 01 — Choose a Workflow

For each scenario, pick the best workflow and explain why.

## Scenarios

**A.** Team of 3, SaaS web app, deploying to production 5× per day.

**B.** Team of 15, mobile app, monthly App Store releases with QA cycles.

**C.** Solo developer maintaining an open source npm package with semantic versioning.

**D.** Startup with 2 developers wanting simplicity and fast iteration.

## Bonus
Pick one scenario, set up a demo repo with the right branch structure, and make 3 commits following that workflow.
