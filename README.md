- [ ] Use Conventional Commits for automated versioning
- [ ] Set up Git hooks with Husky

## Workflow Comparison

| Workflow | Best For | Branches |
|---------|---------|----------|
| GitFlow | Versioned releases | `main`, `develop`, `feature/*`, `release/*`, `hotfix/*` |
| Trunk-Based | Continuous deployment | Only `main` |
| GitHub Flow | Small teams, web apps | `main` + short feature branches |
