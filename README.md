# Chapter 02 — Branching & Merging (Deep Dive)

> **Estimated time:** 3–4 hours | **Difficulty:** Beginner–Intermediate | **Prerequisites:** Chapter 01

## Learning Objectives

- [ ] Explain how Git stores branches internally
- [ ] Distinguish between fast-forward and three-way merges
- [ ] Resolve merge conflicts manually
- [ ] Use `git rebase` to create linear history
- [ ] Explain merge vs. rebase and when to use each
- [ ] Use `git stash` to shelve work in progress
- [ ] Use `git reflog` to recover from mistakes

## Key Commands

```bash
git merge --no-ff <branch>
git merge --abort
git rebase <branch>
git stash
git stash pop
git stash list
git reflog
```
