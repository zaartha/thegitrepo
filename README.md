# Chapter 03 — Remotes & Collaboration

> **Estimated time:** 3–4 hours | **Difficulty:** Intermediate | **Prerequisites:** Chapters 01–02

## Learning Objectives

- [ ] Manage multiple remotes in a single repository
- [ ] Use `git fetch` strategically before merging
- [ ] Understand the fork-based contribution workflow
- [ ] Work with pull requests: create, review, and merge
- [ ] Use `git blame` to trace the origin of any line
- [ ] Use `git bisect` to find which commit introduced a bug
- [ ] Prune stale remote references with `git fetch --prune`

## Key Commands

```bash
git remote add upstream <url>
git fetch --prune
git blame <file>
git bisect start / good / bad / reset
git bisect run <test-script>
```
