# Contributing

Found a typo or broken command? Contributions are welcome.

## How to Contribute

1. Fork the repository: `https://github.com/zaartha/thegitrepo`
2. Create a branch: `git switch -c fix/your-description`
3. Make your changes
4. Commit: `git commit -m "fix: correct example in chapter 01"`
5. Push and open a pull request against `main`

## Guidelines

- One fix per pull request
- Test every command you add or modify
- For new chapters, open an issue first to discuss scope

## Reporting Issues

Open a GitHub issue at https://github.com/zaartha/thegitrepo/issues with:
- Chapter and section
- Description of the issue
- Your Git version (`git --version`) and OS
